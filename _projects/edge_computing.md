## Edge Computing Gateway
 

Designed and implemented an Android-based edge computing gateway for the WSO2 IoT Server. Since the gateway runs on Android, it is optimized to support lightweight IoT devices—for example, collecting data from sensors and controllers in household appliances like air conditioners and making decisions based on the received inputs. WSO2 Siddhi was used as the complex event processor.
